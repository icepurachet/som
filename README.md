# ส้ม — วันนี้กินอะไรดี?

เว็บ static ภาษาไทย ไม่ต้องติดตั้งแพ็กเกจ ไม่ใช้ API key และไม่มีขั้นตอน build

## เปิดใช้งาน
1. เปิดโฟลเดอร์ som ด้วย VS Code
2. คลิกขวา index.html → Open with Live Server
3. หรือดับเบิลคลิก index.html เพื่อใช้แบบออฟไลน์ได้ทันที (ลิงก์แหล่งราคาต้องใช้อินเทอร์เน็ต)

## ไฟล์
- index.html: โครงหน้าเว็บ
- styles.css: การจัดวาง สี ภาพประกอบ CSS และ responsive
- data.js: เมนู ราคา สาขา และ URL แหล่งราคา แก้ไขได้โดยตรง
- app.js: การกรอง สุ่ม ตรวจตัวเลข และแสดงผล
- SOURCES.md: บันทึกที่มาของข้อมูล

## วิธีใช้
เลือกหนึ่งใน 7 โหมด ตั้งงบ/ช่วงราคา แล้วกดสุ่ม โหมดอาหาร ของหวาน และเครื่องดื่มจะใช้ตัวกรองร่วมกับหมวดที่เลือก หากหมวดไม่ตรงกันจะไม่มีผลลัพธ์ ให้เลือก “ทั้งหมด” หรือล้างตัวกรอง

สุ่มร้านให้โอกาสเท่ากันในแต่ละร้านที่ผ่านตัวกรอง สุ่มประเภทอาหารเลือกประเภทก่อนเลือกเมนู ไม่สุ่มเวลาเปิดร้านหรือรับรองว่าร้านเปิดอยู่ ชาเลนจ์เป็นไอเดียกิจกรรมพร้อมเมนู 1 รายการ ไม่มีการบวกงบของเพื่อน

สุ่มงบเลือกจำนวนเต็มจากช่วงราคาที่กำหนด (รวมปลายทั้งสองด้าน) แล้วปรับช่องงบให้อัตโนมัติ ตัวเลขงบอาจต่ำจนไม่มีเมนูได้ ระบบไม่แต่งราคาหรือเมนูเพิ่ม

## ปรับข้อมูล
เพิ่ม object ใน SOM_DATA.menus โดยใช้ id ที่ไม่ซ้ำ พร้อม name, price, source, category, type, emoji
source ต้องตรงกับคีย์ใน SOM_DATA.sources; category ใช้ อาหาร / ของหวาน / เครื่องดื่ม
ราคาเป็นตัวเลขบาทต่อรายการ จากแหล่งที่ตรวจได้จริงเท่านั้น หากราคาเปลี่ยนให้แก้ข้อมูลและวันที่ตรวจใน data.js, index.html และ SOURCES.md ให้ตรงกัน

## ขอบเขตราคา
ตรวจหน้าเว็บ 29 กันยายน 2569 แต่แหล่งราคาไม่ได้เปิดเผยวันที่แก้ไขล่าสุด จึงยืนยันได้เฉพาะราคาที่เผยแพร่บนหน้าเว็บ ไม่ใช่การโทรยืนยันหน้าร้าน ไม่มีการอัปเดตอัตโนมัติ ไม่รวมค่าส่ง ค่าบริการ ภาษีหรือตัวเลือกเพิ่มที่อาจเรียกเก็บ ภาพอาหารเป็นภาพประกอบ/อีโมจิ ไม่ใช่ภาพเมนูจากร้าน
